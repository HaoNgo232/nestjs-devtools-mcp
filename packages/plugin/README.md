# @nestjs-devtools-mcp/plugin

Internal runtime introspection plugin for [`nestjs-devtools-mcp`](https://www.npmjs.com/package/nestjs-devtools-mcp).

[![npm version](https://img.shields.io/npm/v/@nestjs-devtools-mcp/plugin.svg)](https://www.npmjs.com/package/@nestjs-devtools-mcp/plugin)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

---

## Notice

You do not need to install or import this package manually in your NestJS project.

This module is automatically injected into memory at application startup when using the `nestjs-devtools-mcp` preload hook (`npx nestjs-devtools-mcp init`).

For complete setup instructions, please refer to the main repository documentation:
👉 [nestjs-devtools-mcp](https://github.com/HaoNgo232/nestjs-devtools-mcp)
